# Telegram-бот Эрциона

Бот **@ErcionGay** работает на Cloudflare Workers, а анкеты, календарь и очередь уведомлений сохраняет в D1. После размещения компьютер можно выключать.

В меню игрока четыре кнопки:

- **Правила и сайт** — правила, механики, карта и досье стран.
- **Подать анкету** — имя игрока, название страны и короткое описание; затем проверка и отправка.
- **Календарь** — игровой год и время до следующего года. Двое реальных суток равны одному игровому году.
- **Кубик d100** — случайное число от 1 до 100. Результат действия определяет куратор.

Админ-панель открывает очередь анкет, принятые и отклонённые заявки. Администратор принимает анкету либо указывает причину отказа; бот отправляет ответ игроку. В этой же панели можно запустить, поставить на паузу или перенастроить календарь. Начальное состояние — **1601 год, пауза**.

## Запуск

Нужны Node.js 22.13 или новее, токен BotFather и аккаунт Cloudflare. Команды выполняются из папки `bot`:

```powershell
npm.cmd install
npm.cmd run prepare
```

В `.dev.vars` укажите `BOT_TOKEN`. Остальные секреты создаются автоматически. Затем:

```powershell
npm.cmd run login
npm.cmd run deploy
```

Первая команда открывает вход Cloudflare в браузере и выводит код подтверждения. Если страница попросит код, введите его из терминала и разрешите доступ Wrangler. Вторая проверяет токен Telegram, подготавливает базу и миграции, размещает Worker, добавляет секреты и подключает вебхук.

После размещения откройте локальный файл `.wrangler/ADMIN-START.md`. Его ссылка подключает первого администратора при нажатии **Start** в Telegram. Она действует один раз. Куратор затем открывает **Админ-панель → Настроить календарь → Запустить / продолжить**.

При необходимости администраторов можно задать заранее через `ADMIN_IDS` в `.dev.vars`: до пяти числовых Telegram ID через запятую. Тогда доступ получают эти пользователи, а ссылка служит для открытия бота.

Секреты хранятся в локальном `.dev.vars` и в секретах Cloudflare Worker. Локальные настройки, ссылка первого администратора и данные разработки исключены из Git.

## Использование

Анкеты заполняются в личном чате с ботом. `/status` показывает состояние последней заявки, `/cancel` отменяет текущую форму. Для отклонённой анкеты можно отправить исправленный вариант.

В группе работают `/roll` и `/calendar`. Если отправить `/roll` ответом на пост с действием, бот прикрепит результат к этому посту. Telegram выдаёт d100 как текст; бросок и ссылка на исходное сообщение сохраняются в базе.

Одобрение анкеты фиксируется в боте. Досье страны куратор оформляет через существующий редактор сайта.

## Проверки

```powershell
npm.cmd test
npm.cmd run check
```

Проверки используют SQLite и подменяют обращения к Telegram. Они проверяют права, одновременное рассмотрение, повторную доставку обновлений, заполнение анкет, паузу календаря, границу 48 часов, d100 и повторную отправку уведомлений после временной ошибки.

Cron раз в минуту доставляет оставшиеся уведомления. Технические записи обработки и доставленные уведомления очищаются через 30 дней; анкеты и результаты бросков сохраняются.

Бот рассчитан на бесплатные лимиты [Workers](https://developers.cloudflare.com/workers/platform/pricing/) и [D1](https://developers.cloudflare.com/d1/platform/pricing/).
