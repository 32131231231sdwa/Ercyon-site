# Как править сайт без программиста

Инструкция обычными словами. Всё делается в браузере — с компьютера или с телефона.
Если сайт ещё не опубликован, начните с файла **БЫСТРЫЙ-СТАРТ.md** (три шага, 10 минут).

---

## Что вообще происходит

| Что это | Где живёт | Кто трогает |
|---|---|---|
| Тексты разделов | папка `content` | **вы**, через панель |
| Внешний вид | папки `templates`, `static` | никто, всё уже сделано |
| Публикация | Netlify | происходит сама |

Вы пишете текст в панели → панель сохраняет его в репозиторий → Netlify замечает
изменение и за 20–40 секунд пересобирает сайт. **Ничего перезапускать не нужно,
программист не нужен.**

---

# ЧАСТЬ 1. Панель редактора

## Как войти

`ваш-адрес/admin/` → **Sign in with GitHub**. Всё.

## Как поставить на телефон

Панель полностью рассчитана на телефон — в ней можно жить с мобильного.

1. Откройте `/admin/` в браузере телефона.
2. Меню браузера → **«На экран "Домой"»** (Safari) или **«Установить приложение»** (Chrome).
3. Появится иконка на домашнем экране, панель открывается как приложение.

Если сначала открыли панель на компьютере — она предложит **QR-код**. Сканируете
телефоном и попадаете внутрь уже авторизованным.

## Что внутри

| Раздел панели | Что там |
|---|---|
| **Настройки → Основные настройки сайта** | название, девиз, Telegram, сезон, разделы меню |
| **Настройки → Подписи интерфейса** | все надписи сайта: кнопки, заголовки списков, названия полей |
| **Настройки → Главная страница** | текст на главной |
| **Страницы** | правила, лор, магия, механики, карты — всё обычное содержимое |
| **Страны** | досье держав |
| **Новости** | мировые вести и газеты игроков |
| **Договоры** | реестр пактов |

# ЧАСТЬ 2. Как править каждый день

## Поменять текст существующей страницы

**Страницы** → выберите нужную → правьте → **Save / Publish**.
Через полминуты обновите сайт — текст новый.

## Добавить новую страницу

**Страницы → Create** (плюсик), заполните:

| Поле | Что писать | Пример |
|---|---|---|
| Заголовок | название, как увидят игроки | `Бестиарий` |
| Раздел меню | выбирается из списка ваших разделов | `Лор` |
| Порядок в меню | чем меньше число, тем выше | `35` |
| Адрес страницы | латиницей, без пробелов | `bestiary` |
| Короткое описание | одно предложение | `Кто живёт в чащах Пределов.` |
| Текст страницы | сам текст | … |

Сохранили — страница **сама появилась** в боковом меню, в хлебных крошках и в поиске.
Дописывать ничего в коде не надо.

## Добавить новый раздел меню

**Настройки → Основные настройки сайта → Разделы меню → Add**:

- **Служебное имя** — латиницей, например `magic-school` (станет частью адреса)
- **Название** — как в меню, например `Школы магии`
- **Значок** — выбирается из 33 значков, рядом с названием стоит эмодзи-подсказка.
  Посмотреть, как выглядит каждый: **`ваш-адрес/admin/icons.html`**
- **Описание раздела** — строчка под названием

Порядок разделов меняется перетаскиванием. После сохранения новый раздел сразу
появится в списке «Раздел меню» у страниц.

## Убрать раздел меню

Там же — кнопка удаления у нужного раздела.

**Страницы из удалённого раздела не пропадут.** Они соберутся в раздел «Прочее» —
откройте каждую и выберите ей новый раздел. Так ничего нельзя потерять случайно.

## Поменять любую надпись на сайте

**Настройки → Подписи интерфейса.** Там лежит буквально каждая надпись, которая не
является текстом страницы: «Обзор раздела», «Последние вести», «Все новости»,
«Обновлено», «Действует / Пала», «В силе / Нарушен», «Сейчас в мире», названия полей
в досье стран, текст страницы «не найдено» и так далее.

Подписи разбиты по группам — разворачивайте нужную. Если поле очистить, вернётся
значение по умолчанию.

## Добавить страну

**Страны → Create**. Заполняете поля (правитель, столица, ресурсы, геральдический
цвет из списка), внизу пишете досье. Удобно делать заголовками:

```
## Правление
## Земли и хозяйство
## Внешние дела
## Хроника
```

Страна сама появится в каталоге `/countries/` карточкой с флажком выбранного цвета.

## Добавить новость

**Новости → Create**. Дата, автор, тип (мировая новость или газета игроков).
Свежие новости автоматически показываются на главной в блоке «Последние вести».

## Добавить договор

**Договоры → Create**. В поле «Стороны» пишите названия стран **точно так же**,
как они названы в разделе «Страны» — тогда на странице договора появятся ссылки на
страны, а на страницах стран — ссылка на договор.

## Поменять год, режим сезона, девиз, ссылку на Telegram

**Настройки → Основные настройки сайта.** Блок «Статус сезона» — это то, что видно
на главной большой плашкой с сургучной печатью.

## Вставить картинку

В тексте нажмите кнопку картинки → перетащите файл (или выберите из галереи телефона).
Либо напишите руками:

```
![Что на картинке](/img/uploads/имя-файла.jpg "Подпись под картинкой")
```

Карты кладутся так же — в разделе «Карты» уже стоят заглушки, просто замените файл.

## Что происходит после сохранения

1. Панель отправляет текст в репозиторий (5 секунд).
2. Netlify видит изменение и пересобирает сайт (20–40 секунд).
3. Обновляете страницу — текст новый.

Посмотреть, идёт ли сборка: Netlify → вкладка **Deploys**. Зелёная надпись
**Published** — готово.

# ЧАСТЬ 3. Соавторы

GitHub → ваш репозиторий → **Settings → Collaborators → Add people** → ник соавтора.

Он принимает приглашение (придёт на почту), открывает `/admin/`, входит своим
GitHub — и правит вместе с вами. Никаких отдельных паролей.

Все правки подписаны автором: GitHub → вкладка **Commits** видно, кто что менял.
Если кто-то удалил лишнее — оттуда же можно вернуть.

> Панель не умеет разруливать одновременную правку одной страницы двумя людьми.
> Договоритесь, кто какой раздел ведёт, — этого достаточно.

# ЧАСТЬ 4. Шпаргалка по оформлению текста

В редакторе есть кнопки, но значками быстрее.

```
## Большой заголовок
### Заголовок поменьше

Обычный абзац. **Жирным** выделяют важное, *курсивом* — оттенок смысла.

- маркированный список
- второй пункт

1. нумерованный список
2. второй пункт

> Цитата или выдержка из хроники.

[Ссылка на другую страницу](/lore/magic/)

![Подпись картинки](/img/uploads/kartinka.jpg)

❦
```

Отдельная строка со знаком `❦` превращается в растительный разделитель.

### Красивые врезки

Строка открытия, текст, строка `:::`:

```
:::seal Важно
Заявки принимаются до конца недели.
:::

:::note Заметка
Мелкое пояснение, которое не хочется прятать в скобки.
:::

:::warn Осторожно
Нарушение этого правила — исключение из сезона.
:::

:::quote Из хроники
«И замолчали птицы, и это был Тихий Год.»
:::
```

- `seal` — с сургучной печатью, для главного
- `note` — спокойная заметка
- `warn` — предупреждение
- `quote` — выдержка из летописи

Заголовки этих врезок («Важно», «Заметка»…) тоже меняются в
**Настройки → Подписи интерфейса → Заголовки врезок**.

### Таблица

```
| Ресурс | Где добывают | Цена |
|---|---|---|
| Соль | Соляная Межа | 12 |
| Железо | Каменные гряды | 8 |
```

На телефоне широкие таблицы прокручиваются пальцем — это нормально.

# ЧАСТЬ 5. Если что-то пошло не так

**Панель не открывается / не пускает.**
Проверьте, что вы вошли тем аккаунтом GitHub, у которого есть доступ к репозиторию
(владелец или collaborator).

**Сохранил, а на сайте старый текст.**
Подождите минуту и обновите страницу с очисткой кэша: `Ctrl+F5` (на телефоне —
закрыть и открыть вкладку). Если не помогло, посмотрите Netlify → **Deploys**:
красная надпись **Failed** означает ошибку сборки — откройте её и прочитайте
последние строки, там написано, в каком файле беда.

**Сборка падает с жалобой на YAML.**
Значит в каком-то поле оказалось двоеточие или лишняя кавычка. Возьмите такое
значение в кавычки: `Карты: границы` → `"Карты: границы"`. Через панель такое почти
невозможно, но если правили файл руками — смотрите туда.

**В логе сборки написано «Страницы без раздела».**
Вы удалили или переименовали раздел, а страницы в нём остались. Они не потерялись —
лежат в разделе «Прочее». Откройте каждую и выберите существующий раздел.

**В логе сборки написано «Ссылки на несуществующие страницы».**
Где-то в тексте ссылка на страницу, которой нет (например, поменяли адрес страницы,
а ссылки на неё остались). Сборщик пишет, на какой странице искать.

**Случайно удалил страницу.**
GitHub хранит всю историю: репозиторий → **Commits** → найдите нужный момент →
можно вернуть файл.

**Хочу поменять цвета или шрифты.**
Файл `static/css/site.css`, в самом верху блок с цветами. Меняется одно значение —
меняется весь сайт.

**Основная панель сломалась.**
Есть запасная по адресу `/admin-classic/` — та же самая начинка, старый движок.
Для входа в неё в Netlify нужно настроить вход через GitHub:
Site configuration → Access control → OAuth → Install provider → GitHub
(понадобится создать OAuth App в настройках GitHub). Основная панель этого не требует,
поэтому запасная нужна редко.

# Приложение. Правка без панели

Текст можно править прямо на GitHub: репозиторий → папка `content` → нужный файл →
карандаш **Edit** → правьте → **Commit changes**. Netlify так же пересоберёт сайт.

Каждый файл устроен одинаково: сверху между строчками `---` служебные поля,
ниже — обычный текст.

---

# Приложение. Проверить сайт у себя на компьютере

Нужен только Node.js (nodejs.org, кнопка LTS). Дальше в папке проекта:

```
node build.mjs --serve
```

Откроется `http://localhost:4321`. Никаких `npm install` — библиотек у проекта нет.
