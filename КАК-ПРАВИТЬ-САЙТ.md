# Как править справочник

Сайт содержит правила и механики игры. Редактор сохраняет изменения в GitHub, после чего GitHub Actions собирает и публикует обновление.

## Панель редактора

Откройте https://32131231231sdwa.github.io/Ercyon-site/admin/ и войдите через GitHub. У аккаунта должен быть доступ к репозиторию 32131231231sdwa/Ercyon-site.

| Раздел панели | Содержимое |
|---|---|
| Правила и механики | Технические страницы |
| Настройки → Основные настройки сайта | Название, описание, Telegram и два раздела меню |
| Настройки → Подписи интерфейса | Меню, поиск, ошибка 404 и врезки |
| Настройки → Главная страница | Вступление и пояснение к справочнику |

## Изменить страницу

Выберите «Правила и механики», откройте нужную запись и измените текст или описание. Нажмите «Сохранить». После успешной публикации обновите сайт.

## Добавить техническую страницу

В разделе «Правила и механики» нажмите кнопку создания записи.

| Поле | Значение |
|---|---|
| Заголовок | Название материала |
| Раздел меню | Правила или механики |
| Порядок в меню | Меньшее число поднимает страницу выше |
| Адрес страницы | Латиница, цифры и дефисы: например research |
| Короткое описание | Одно предложение для карточки и поиска |
| Текст страницы | Правило или описание механики |

Страница категории mechanics с адресом research появится по пути /mechanics/research/. Переключатель «Эта страница — весь раздел» даёт ей адрес самого раздела, как у /rules/. В одном разделе таким может быть только один материал.

## Изображения и оформление текста

Изображение можно вставить через редактор Markdown. Загруженные файлы находятся в static/img/uploads/. Для больших изображений сборщик использует уменьшенные копии, когда они доступны.

~~~markdown
## Заголовок

**Важная мысль**, обычный текст.

[Исследования](/mechanics/research/)

![Описание схемы](/img/uploads/schema.webp "Подпись")

:::note Примечание
Пояснение к механике.
:::

| Параметр | Значение |
|---|---|
| Срок | Один ход |
~~~

Также доступны врезки seal, warn и quote. На телефоне широкие таблицы прокручиваются в сторону.

## Чтение и сохранения

Звёздочка добавляет материал в избранное. Кнопка «Офлайн» сохраняет текст и оформление, до 30 страниц на устройстве. Иллюстрации могут требовать подключения.

В меню чтения можно изменить размер текста и фон. Главная предлагает продолжить чтение с сохранённой позиции. Удалённые из справочника материалы исчезают из избранного, истории и офлайн-копий после обновления сайта.

## Если правка не появилась

Откройте [GitHub Actions](https://github.com/32131231231sdwa/Ercyon-site/actions) и проверьте последний запуск. Пока публикация выполняется, сайт показывает предыдущую сборку. При ошибке откройте шаг «Сборка и проверка сайта» и прочитайте сообщение.

Обновление с очисткой браузерного кеша: Ctrl+F5 на компьютере.

Случайно удалённый материал можно восстановить через историю коммитов GitHub. Сохраняйте его в категории rules или mechanics.

## Изменить файл напрямую

На GitHub откройте content/pages/, выберите Markdown-файл, нажмите редактирование и сохраните коммит в main. Название, адрес и описание находятся между строками ---; ниже расположен текст.

## Локальная проверка

Нужен Node.js 18+. В PowerShell, открытом в папке проекта:

~~~powershell
npm.cmd test
node build.mjs --serve
~~~

Адрес локального сайта: http://localhost:4321. Дополнительные проверки телефона и панели описаны в [README](./README.md).
