# Ercyon — вики ролевого проекта

Статическая вики ролевого проекта «Эрцион»: правила, игровые механики, справочники и карты. Сюжетные записи и досье прошлого сезона удалены, редакторы всех разделов доступны для новых материалов.

Сайт: https://32131231231sdwa.github.io/Ercyon-site/

- [Быстрый старт](./БЫСТРЫЙ-СТАРТ.md)
- [Как редактировать сайт](./КАК-ПРАВИТЬ-САЙТ.md)

## Локальная сборка

Нужен Node.js 18+. Библиотеки Markdown и YAML лежат в vendor/, установка пакетов для сборки не требуется.

~~~powershell
node build.mjs
node build.mjs --serve
npm.cmd test
~~~

Результат сборки находится в dist/. Локальный сервер открывается по адресу http://localhost:4321.

Для проверки GitHub Pages задайте BASE_PATH=/Ercyon-site и при сборке, и при проверках.

## Редактор и публикация

Основная панель — /admin/ (Sveltia CMS 0.182.0), резервная — /admin-classic/ (Decap CMS). Обе используют admin/config.yml. Для входа в основную панель нужен аккаунт GitHub с доступом к репозиторию.

В редакторе доступны «Страницы», «Страны», «Новости», «Договоры», «Войны» и «Настройки». Список разделов для обычных страниц берётся из настроек меню.

Изменения в main автоматически собираются, проверяются и публикуются на GitHub Pages через .github/workflows/deploy.yml. Хостинг получает dist/. Удалённые материалы остаются в истории Git.

## Чтение на телефоне

Нижнее меню открывает главную, правила, карты, поиск и остальные разделы. Избранное, размер текста и прогресс чтения сохраняются на устройстве. Можно сохранить до 30 страниц для чтения без интернета.

При обновлении справочник удаляет ссылки и офлайн-копии снятых с публикации материалов, сохраняя доступные записи и настройки чтения.

## Проверки

~~~powershell
npm.cmd test
node tools/check-mobile.cjs
node tools/check-admin.cjs
~~~

Для браузерных проверок нужен Playwright с Chromium. PLAYWRIGHT_MODULE задаёт путь к пакету, CHROMIUM_PATH — к браузеру, SCREENSHOT_DIR — папку снимков. CMS_SCRIPT_FILE позволяет использовать скачанную закреплённую версию Sveltia CMS.

Проверка сайта охватывает поиск, навигацию, атлас, избранное, продолжение чтения, ширины 320–1440 пикселей, работу без JavaScript, удалённые адреса и миграцию офлайн-копий. Проверка редактора сохраняет страницу и новый раздел меню, затем открывает их после обновления. Она работает с копией контента в отдельном браузерном хранилище.

## Файлы проекта

~~~text
content/settings.yml    название, описание, Telegram и разделы меню
content/labels.yml      подписи меню, поиска, ошибки и врезок
content/home.md         вступление на главной
content/pages/*.md     правила, справочники и карты
content/countries/    новые досье стран
content/news/         новые новости
content/treaties/     новые договоры
content/wars/         новые военные хроники
templates/             разметка
static/                стили, скрипты и иллюстрации справочника
assets/*.b64.json       шрифты и оформление, распаковываемые при сборке
admin/                 основная панель
admin-classic/         резервная панель
vendor/                локальные библиотеки
tests/                 проверки
tools/                 браузерные проверки и вспомогательные скрипты
build.mjs              сборщик
dist/                  собранный сайт, не хранится в Git
~~~

У страницы есть YAML-шапка и текст Markdown:

~~~markdown
---
title: Исследования
category: mechanics
order: 20
slug: research
summary: Как проводить исследования.
---

## Порядок исследования

Текст механики.
~~~

Для страницы, представляющей весь раздел, предусмотрено section_home: true. Врезки оформляются блоками :::seal, :::note, :::warn и :::quote.
