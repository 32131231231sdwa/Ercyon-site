# Ercyon — сайт-вики ролевого проекта

Статический сайт: тексты в Markdown, оформление отдельно, публикация автоматическая.
**Зависимостей нет** — нужен только Node.js 18+. Никаких `npm install`.

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/32131231231sdwa/Ercyon-site)

## Быстрый старт для разработчика

```bash
node build.mjs           # собрать сайт в dist/
node build.mjs --serve   # собрать и открыть на http://localhost:4321
```

## Как устроено

```
content/            ← ВЕСЬ ТЕКСТ САЙТА
  settings.yml        название, девиз, сезон, ссылка на Telegram, разделы меню
  labels.yml          все служебные подписи интерфейса
  home.md             тексты главной страницы
  pages/*.md          обычные страницы (правила, лор, магия, механики…)
  countries/*.md      досье стран
  news/*.md           новости
  treaties/*.md       договоры
templates/          вёрстка
  layout.mjs          каркас: шапка, меню, крошки, подвал, поиск
  views.mjs           разметка типов страниц (главная, страна, договор, новость…)
  icons-page.mjs      шпаргалка со значками → /admin/icons.html
static/             всё, что копируется на сайт как есть
  css/site.css        оформление (цвета — в самом верху файла)
  css/fonts.css       подключение шрифтов из репозитория
  js/app.js           меню, поиск, оглавление
  img/decor/          рукописный SVG-спрайт: 33 значка, лозы, печати
  img/uploads/        картинки, загруженные через панель
assets/             шрифты и картинки оформления в текстовом виде (base64),
                    распаковываются в dist/ при сборке — см. assets/README.md
admin/              панель редактора Sveltia CMS (/admin/)
admin-classic/      запасная панель Decap CMS (/admin-classic/), тот же config.yml
vendor/             marked и js-yaml — лежат в репозитории, не ставятся из сети
build.mjs           сборщик
tools/              вспомогательные скрипты (картинки, шрифты, файл-предпросмотр)
dist/               результат сборки (в git не хранится)
```

## Ключевая идея: меню строится из контента

У каждой страницы в шапке есть `category` и `order`. Сборщик группирует страницы по
категориям из `settings.yml` и сам рисует боковое меню, обзоры разделов, хлебные
крошки и поисковый индекс.

**Чтобы добавить страницу — достаточно добавить .md-файл.** Чтобы добавить раздел —
дописать блок в `categories` в `settings.yml` (или нажать «Add» в панели). Код при
этом не меняется.

Если раздел удалили, а страницы остались — они не теряются: попадают в раздел
«Прочее», а сборка пишет об этом предупреждение.

### Адреса страниц

| Что | Файл | Адрес |
|---|---|---|
| страница категории `base` | `content/pages/rules.md` | `/rules/` |
| страница другой категории | `content/pages/magic.md` (`category: lore`) | `/lore/magic/` |
| обзор раздела | — (создаётся сам) | `/lore/` |
| страна | `content/countries/valenholm.md` | `/countries/valenholm/` |
| договор | `content/treaties/solyanoy-pakt.md` | `/treaties/solyanoy-pakt/` |
| новость | `content/news/2026-08-01-slug.md` | `/news/slug/` |

## Формат файлов

Между строками `---` — служебные поля, ниже — текст.

```markdown
---
title: "Магия: Живица"      # двоеточие в значении → в кавычки
category: lore
order: 20
slug: magic
summary: Что такое Живица и чем за неё платят.
---

## Пять школ
Текст…
```

Дополнительно к обычному Markdown работают:

- `❦` отдельной строкой — растительный разделитель;
- блоки `:::seal` / `:::note` / `:::warn` / `:::quote` … `:::` — оформленные врезки.

## Подписи интерфейса

Ни одна надпись не зашита в шаблоны — всё берётся из `content/labels.yml`
через помощник `L('news.empty', 'запасное значение')`. Пустое поле = запасное значение,
поэтому сломать сайт, очистив подпись, нельзя.

## Панель редактора

`/admin/` — **Sveltia CMS** (закреплена версия 0.182.0). Выбрана из-за полноценной
поддержки телефона: адаптивный интерфейс, установка как приложение, вход по QR-коду.
Бэкенд — `github`, вход через аккаунт GitHub с доступом к репозиторию.
Ни Netlify Identity, ни Git Gateway, ни своего OAuth-сервера не нужно.

`/admin-classic/` — **Decap CMS** на том же `admin/config.yml`, на случай проблем
с основной панелью. Требует настройки Netlify OAuth (см. КАК-ПРАВИТЬ-САЙТ.md).

`/admin/icons.html` — шпаргалка со всеми 33 значками разделов, генерируется из спрайта
при сборке.

Обновить панель: поменять номер версии в `admin/index.html`.

## Что делает сборка

1. читает `content/`, разбирает YAML-шапки и Markdown;
2. строит меню, крошки, обзоры разделов, каталоги стран/договоров/новостей;
3. проставляет дату «Обновлено» из истории git (при недоступной истории — дата файла);
4. пишет `dist/` + `search-index.json`, `sitemap.xml`, `robots.txt`, `rss.xml`, `404.html`;
5. проверяет внутренние ссылки и пишет предупреждения в лог;
6. копирует `static/`, обе панели и сырой `content/`.

Полная сборка занимает меньше секунды.

## Публикация

**Netlify** (рекомендуется): настройки в `netlify.toml`, команда `node build.mjs`,
каталог `dist`. Кнопка Deploy выше подставляет репозиторий сама.

**GitHub Pages**: `.github/workflows/deploy.yml`, включается в
Settings → Pages → Source → GitHub Actions. Панель `/admin/` там тоже работает —
Sveltia использует собственный OAuth-клиент.

## Оформление

Цвета и типографика — переменные в начале `static/css/site.css`:

```css
--deep:#14352A;   /* тёмно-зелёный */
--moss:#3E6B4F;   /* мох */
--parch:#F2EBD9;  /* пергамент */
--gold:#B08D4A;   /* старое золото */
--wax:#7C302B;    /* сургуч */
```

Свёрстано mobile-first: телефон — базовые правила, планшет от `46rem`,
закреплённое меню от `62rem`, оглавление справа от `84rem`.

Декор (лозы, ветви-разделители, печати, 33 значка) — рукописный SVG-спрайт
`static/img/decor/sprite.svg`, вставляется в страницу и красится через `currentColor`.

## Служебные скрипты

```bash
node tools/pack-assets.mjs --unpack   # достать шрифты и картинки в static/
node tools/pack-assets.mjs            # упаковать их обратно в assets/
python3 tools/make_assets.py          # пересобрать картинки из исходных фотографий
python3 tools/fetch_fonts.py          # заново скачать шрифты
node tools/make_preview.mjs           # весь сайт одним файлом preview.html (для показа)
```

Проект целиком состоит из текстовых файлов: шрифты и картинки оформления лежат
в `assets/*.b64.json` и разворачиваются при сборке. Поэтому его можно переносить
любым способом, ничего не повредив.
