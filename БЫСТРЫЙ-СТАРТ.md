# Быстрый старт

Справочник уже опубликован: https://32131231231sdwa.github.io/Ercyon-site/

## Изменить правило или механику

1. Откройте [панель редактора](https://32131231231sdwa.github.io/Ercyon-site/admin/).
2. Войдите через GitHub с аккаунтом, имеющим доступ к репозиторию.
3. Выберите «Страницы», откройте страницу, внесите изменения и нажмите «Сохранить».
4. Дождитесь успешной публикации в [GitHub Actions](https://github.com/32131231231sdwa/Ercyon-site/actions), затем обновите сайт.

## Изменить главную или меню

В разделе «Настройки» находятся «Основные настройки сайта», «Подписи интерфейса» и «Главная страница». Чтобы добавить раздел, откройте «Основные настройки сайта → Разделы меню», нажмите «Добавить», задайте служебное имя латиницей и название, затем сохраните. Он появится на сайте после публикации; в редакторе страниц его можно выбрать в поле «Раздел меню».

## Проверить у себя

Нужен Node.js 18+. Откройте PowerShell в папке проекта:

~~~powershell
npm.cmd test
node build.mjs --serve
~~~

Локальный адрес: http://localhost:4321. Сборка находится в dist/.

## Добавить редактора

Откройте настройки репозитория GitHub, раздел Collaborators, добавьте аккаунт соавтора. После принятия приглашения он сможет войти в /admin/ и редактировать материалы.
