# Быстрый старт — три шага

Всё делается в браузере, можно с телефона. Ничего устанавливать не нужно.

---

## Шаг 1. Файлы в репозитории

Проект лежит здесь: **https://github.com/32131231231sdwa/Ercyon-site**

Если репозиторий пуст — распакуйте архив с проектом и загрузите содержимое:
`Add file → Upload files` → перетащить файлы → `Commit changes`.

> Файл `.gitignore` и папка `.github` могут не загрузиться — они начинаются с точки
> и система их прячет. Это нормально, для работы они не нужны.

---

## Шаг 2. Публикация на Netlify

1. Зайдите на **netlify.com**, войдите через GitHub.
2. **Add new project → Import an existing project → GitHub**.
3. Выберите репозиторий **Ercyon-site**.
4. Настройки сборки Netlify подхватит из `netlify.toml` — проверьте, что стоит
   команда `node build.mjs` и каталог `dist`. Нажмите **Deploy**.

> ⚠️ **Не пользуйтесь кнопкой «Deploy to Netlify»**, которую можно встретить в
> readme-файлах. Она не подключает ваш репозиторий, а делает его копию со
> случайным именем и собирает сайт из копии. Панель при этом продолжает писать
> правки в исходный репозиторий — и на сайте ничего не меняется.

### Сразу после деплоя — два обязательных пункта

**а) Открыть сайт для посетителей.** Новые проекты Netlify по умолчанию приватные:
вы их видите, а остальные получают окно входа. Идём в
**Project configuration → General → Visitor access → Project visibility** и ставим
**Public**.

**б) Сменить адрес на человеческий.** **Project configuration → General →
Project details → Change site name** → впишите `ercyon`. Получится `ercyon.netlify.app`.

**Больше ничего настраивать не нужно.** Ни Identity, ни Git Gateway, ни OAuth-приложений.

---

## Шаг 3. Панель редактора

Откройте **`ваш-адрес.netlify.app/admin/`** → кнопка **Sign in with GitHub** → готово.

Вы уже внутри и можете править любой текст сайта.

### Поставить панель на телефон как приложение

1. Откройте `/admin/` в браузере телефона.
2. Меню браузера → **«На экран "Домой"»** (Safari) или **«Установить приложение»** (Chrome).
3. На домашнем экране появится иконка — панель открывается как обычное приложение.

Ещё быстрее: откройте `/admin/` на компьютере — панель сама предложит **QR-код**.
Сканируете телефоном и оказываетесь внутри уже авторизованным, пароль вводить не надо.

## Позвать соавторов

GitHub → репозиторий → **Settings → Collaborators → Add people** → ник соавтора.

Он принимает приглашение, открывает `/admin/`, входит своим GitHub — и правит вместе с вами.
Каждая правка подписана автором, историю видно в репозитории на вкладке **Commits**.

---

## Первое, что стоит сделать

Панель → **Настройки → Основные настройки сайта**:

- **Адрес сайта** — впишите настоящий, например `https://ercyon.netlify.app`
- **Ссылка на Telegram** — проверьте, что стоит ваша группа
- **Статус сезона** — год, режим набора, примечание

Потом замените заглушки карт: раздел **Карты**, вместо картинки-заглушки загрузите свою.
